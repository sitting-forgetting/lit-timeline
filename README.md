# 中国现当代文学时间轴

在线访问：<https://sitting-forgetting.github.io/lit-timeline/>

把两本教材的年表全部结构化，画成一条从 1898 到 2000 年、可以缩放、搜索、自测的时间轴。
纯静态页面，不联网、不装东西，双击即用。

> **数据来源（两本教材）**
> 1. 钱理群、温儒敏、吴福辉《中国现代文学三十年》（修订本）—— 各章「本章年表」
> 2. 洪子诚《中国当代文学史》——「中国当代文学年表（1949—2000）」
>
> 共 **2382 条**，覆盖 1898—2000。其中 **必背 143 条**、常考 465 条。
> 现代部分 1660 条、当代部分 722 条。每条的「出处」都标明出自哪本书、哪一章。

## 它做什么

**1. 九段分期，六条轨道**
分期：前史 / 第一个十年 / 第二个十年 / 第三个十年 / 十七年 / 文革十年 / 新时期 / 九十年代 / 新世纪。
轨道：思潮·论争 / 社团·刊物 / 小说 / 诗歌 / 散文 / 戏剧。
同一年的事落在同一竖列上——横向比同年、纵向看同轨，这是二轮复习最容易糊的地方。

**2. 缩放改变信息密度**
远景只留必背条目（重要度 3），放大逐级展开，再放大到月、日。
重要度按「该条目在全书正文里被 `<书名号>` 引用的次数」排序（刊物名不算，避免《新青年》霸榜）：
≥12 次为必背，≥4 次为常考，其余为了解。必背条目在远景下**永不隐藏**。

**3. 点开一条 = 一张考点卡**
一句话史实（年表原文）／考点（正文里讲这条的段落）／出处（出自第几章）／标签。
出处这一项能直接对回书里那一页去读，不用瞎猜。

**4. 筛选 + 搜索**
按时期（前史 / 第一个十年 / 第二个十年 / 第三个十年 / 延伸）、按轨道、按标签过滤；
搜索覆盖标题、正文摘要、考点、章节名。搜索时命中项优先占位，不会被挤掉。

**5. 复习自测**
随机抽卡：先只给年份和体裁，自己回想；可看提示（书名打码），再揭示答案。
「没记住」自动进待复习，时间轴上带朱砂圈。

**6. 打印背诵版**
按时期分组的 A4 清单。

## 数据是怎么来的

```bash
# 现代部分（钱理群）：各章「本章年表」
python3 scripts/build_from_epub.py 现代文学三十年.epub

# 当代部分（洪子诚）：全书末尾统一年表，合并进现有数据
python3 scripts/build_contemporary.py 当代文学史.epub --merge data/events.js
```

**两本书的年表结构不同**，所以是两个脚本：

| | 钱理群 | 洪子诚 |
|---|---|---|
| 年表位置 | 每章末，共 29 个 | 全书末尾，1 个 |
| 条目量 | 2452 行 | 988 行 |
| 特点 | 大量纯生平行需剔除 | 大量「某报发表某文」，刊物名易被误当条目 |

`build_from_epub.py` 做的事：

1. 解析 EPUB，按「编—章—节」切块，取出 29 个「附录 本章年表」；
2. 把年表行拆成 `年 / 月 / 日 + 事件文本`（2452 行 → 结构化）；
3. 判定轨道：刊物名优先 → 已知名作体裁表 → 本章体裁（本书按体裁分章）→ 正文最近邻；
   体裁同时决定轨道（小说/诗歌/散文/戏剧/思潮/社团刊物）；
4. 过滤纯生平行（"入仙台医专学习"这类不进时间轴）；
5. 按正文词频打重要度；回到正文找讲这条的段落，作为「考点」；
6. 记录章节来源，作为「出处」。

`build_contemporary.py` 额外处理：把《人民日报》《文艺报》这类发表载体从「条目」里剥掉，
改提「批判《武训传》」「塑造新英雄人物问题」这样的真实事件名（这一项修了 29 条）。

**抽取是启发式的，不是人工校对过的。** 2382 条里绝大多数准确，但个别条目的轨道归类、
体裁标注可能有偏差。你过一遍、改 `数据源.csv`，再跑：

```bash
python3 scripts/import_csv.py 数据源.csv --check   # 先校验
python3 scripts/import_csv.py 数据源.csv           # 生成 data/events.js
```

这个脚本会**继承现有 `data/events.js` 里的时期划分、轨道和 meta**，所以往返不会冲掉这本书的结构
（早期版本会，已修）。刷新即生效。字段说明见 [数据填写说明.md](数据填写说明.md)。

## 已知限制

- **两本书的时间下限都是 2000 年**。2000 年后只有 6 条（洪子诚年表末尾带到的）。
  要补新世纪，用 `数据模板.csv` 自己加。
- **同一书名在不同年份出现是正常的**，不要当成重复：比如《青春之歌》1958 年出版、1959 年引发讨论、
  1960 年再版，是三个不同事件。年表记的是「发生了什么」，不是「作品列表」。
- 年表是「文学史事件表」，不是「考点表」：它记录了某年某月谁发表了什么，但不解释为什么重要。
  「考点」一栏是正文摘录，能补一部分，但不等同于你自己整理的答题要点。
- 记忆钩子、易混辨析两栏目前基本为空——这两样得你自己总结才有效，脚本编不出来。
- 1660 条在远景下会做取舍（只显示必背 + 每轨最多 5 行），放大才全见。这是刻意的。
